# Generated data and execution artifacts

This directory contains local inputs and generated artifacts. The repository
includes this guide and an empty-directory placeholder, not datasets or run data.
Do not commit cohort records, derived subsets, embeddings, credentials, or logs.

## Synthetic example

From the repository root with the Memstara environment active:

```bash
python -m memstara.prep.sample
```

The generator writes `dataset.csv` and `okf_synthetic_sample/` here. It overwrites
those sample paths, so preserve any existing data before running it. The default
sample has 1,700 rows, the binary target `outcome`, opaque predictor names, planted
signal, noise, and concepts without a corresponding dataset column. The program
prints the generated column and concept counts; use those rather than a static
count in a guide. See [sample.py](../src/memstara/prep/sample.py).

Configure a run for the sample:

```bash
export AGENTIC_OKF_BUNDLE_DIR="$PWD/outputs/okf_synthetic_sample"
export MEMSTARA_DATASET_PATH="$PWD/outputs/dataset.csv"
export MEMSTARA_OUTPUT_DIR="$PWD/outputs"
export MEMSTARA_OUTCOME_COLUMN=outcome
python scripts/build_matcher_cache.py
python -m memstara.pipeline.board --trials 3 --y-column outcome
```

The matcher build requires its embedding model; pipeline execution also requires
runtime services and provider credentials. Follow the [setup guide](../README.md#get-started).
The target must be excluded from predictors. Selecting another dataset requires
matching outcome settings and a catalogue rebuilt for that dataset.

## Artifact locations

| Location | Purpose |
|---|---|
| `dataset.csv` | Synthetic sample generated by `memstara.prep.sample` |
| `okf_synthetic_sample/` | Generated sample knowledge bundle |
| `matcher_catalog*` | Catalogue, embedding matrix, and identity metadata |
| `sub_*.csv` | Extracted predictor and target subsets |
| `runs/` | Execution configurations, traces, checkpoints, and reports |
| `logs/` | Pipeline logs |

`MEMSTARA_OUTPUT_DIR` redirects subsets and matcher artifacts. Run history and
logs remain under the checkout's `outputs/runs` and `outputs/logs`; see
[paths.py](../src/memstara/paths.py). Paired-model runs also save model, prediction, split,
reproduction, and XAI artifacts at paths recorded in their manifests. Follow those
recorded paths rather than assuming every file lives directly under `runs/`.
See the [execution audit](../DEVELOPER_GUIDE.md#read-and-verify-an-execution).
Not every optional artifact appears in every run. Preserve the run's recorded configuration when interpreting its output.

A bundle can live outside this directory: set `AGENTIC_OKF_BUNDLE_DIR` to its
absolute path. `okf_<source>_<contents>` is a naming convention for generated
bundles, not a directory that the loader automatically discovers.
