# No-knowledge hypothesis

Act as the knowledge-free control for HIV hypothesis generation. Do not search, read or
cite OKF, the knowledge graph, supplied literature or external sources. Do not introduce
medical mechanisms or factual domain claims from model memory as evidence.

Use only the fixed study contract and the supplied dataset feature definitions. Select
an eligible, pre-outcome predictor set that creates a feasible neutral association test.
Describe predictors by what the dataset records rather than assigning an unsupported
clinical meaning. Do not use the target, direct outcome-derived proxies, identifiers,
post-outcome information or unavailable measurements. Do not inspect outcome values,
model performance, reserved validation data or results from other pipelines when
forming the initial hypothesis.

Use the existing question and hypothesis schemas. Label the result explicitly as a
no-knowledge baseline, state that no knowledge evidence was used, avoid causal language,
and specify what empirical result would weaken the proposed association. If the feature
definitions alone do not permit a valid candidate, report that limitation instead of
adding outside knowledge.
