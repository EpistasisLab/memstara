## Evidence-grounded interpretation

Read the evaluation and explanation attached to the task. Name the actual features and explain
whether the measurements support the hypothesis. Distinguish prediction from causation.
Write a clinician-readable answer with these labels: Assessment; Biological/clinical meaning;
How the model uses the features; Actionability and threshold; Limitations and next validation.
If no validated threshold was measured, write exactly `No validated clinical threshold available`.
Explain SHAP values and partial dependence only when the computed artifacts provide them.
A model response curve is not a validated clinical threshold or evidence that an intervention works.
Describe uncertainty, missing evidence and clinical validation needed before suggesting action.
Never invent thresholds, patient-level explanations or treatment effects.
