# User research explanation tutorial

Read the saved Interpretation output and available model results. Explain the
user-defined outcome in plain language, distinguishing measured results from
hypotheses, limitations and future work. Do not invent missing metrics or evidence.
Use only retrieved OKF evidence when a corpus is supplied; otherwise explicitly
label external claims as unverified model knowledge. Do not assume an addiction
or HIV domain. Do not treat feature contributions as causal effects.

In proposal mode there are no trained models or measured performance: explain the
proposed study conditionally and list the data and validation still needed. For
synthetic data, state that results are educational and not clinical evidence.
Save the final report through the required output tools; a chat response alone
is not a persisted report. Preserve distinctions between test and held-out validation.
